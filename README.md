Навчання без бар’єрів
Опис проєкту:
«Навчання без бар’єрів» — це вебсайт, присвячений темі інклюзивної освіти. Його мета — привернути увагу до рівних можливостей для навчання та показати важливість створення доступного й комфортного освітнього середовища для кожного учня.

Мета роботи:

Популяризувати ідею інклюзивної освіти.
Підкреслити важливість рівного доступу до навчання.
Привернути увагу до потреб учнів з різними освітніми потребами.
Створити зрозумілий і візуально привабливий вебсайт.

Використані технології:

HTML — структура вебсторінки.
CSS — оформлення, кольори, розташування елементів і стилізація зображення.
Зовнішнє зображення — ілюстрація на тему інклюзивної освіти.

Основні можливості:

Відображення головного блоку з назвою та тематичним зображенням.
Візуальне оформлення сторінки в єдиному стилі.
Представлення інформації про інклюзивне навчання.
Адаптація вмісту для зручного перегляду на різних пристроях — за умови наявності відповідних CSS-правил.

Структура проєкту:

navchannya-bez-barieriv/
├── index.html
├── style.css
└── README.md

Як запустити проєкт:
Завантажте або скопіюйте файли проєкту в одну папку.
Відкрийте файл Навчання без бар'єрів.html у браузері.
Перегляньте сторінку та її вміст.
Для відображення головного зображення потрібне підключення до інтернету, оскільки воно завантажується із зовнішнього ресурсу.
